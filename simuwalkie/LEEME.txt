WALKIE-TALKIE · simulador en red local
=======================================

Que hace: varios usuarios abren la misma direccion (la IP del equipo que ejecuta el
servidor), eligen un canal (1-16) y hablan por turnos, como en un walkie real.

Requisitos: Node.js 10 o superior (recomendado 18 o 20 LTS). No hay que instalar
paquetes ni openssl: el servidor crea solo el certificado HTTPS (carpeta "certs").
Si alguien escribe http:// en lugar de https:// con el mismo puerto, se le redirige.

1) En el equipo "anfitrion" (basta con server.js: la pagina va incrustada; si hay un
   index.html al lado, se usa ese):
      node server.js
   Opciones:   PORT=9000 node server.js      otro puerto
               CODE=1234 node server.js      exige un codigo de sala
               HTTP=1 node server.js         sin HTTPS (microfono solo en localhost)

2) El servidor muestra las direcciones, por ejemplo https://192.168.1.20:8443
   Cada usuario la abre en su navegador (movil u ordenador, misma Wi-Fi o red).

3) La primera vez el navegador avisa del certificado autofirmado: Avanzado > Continuar.
   Es necesario: sin HTTPS los navegadores bloquean el microfono.

4) Escriba su nombre, elija canal, ENTRAR, permita el microfono y mantenga pulsado
   "PULSAR PARA HABLAR" (o la barra espaciadora). Solo habla uno a la vez por canal.

UBUNTU / DEBIAN
---------------
Compruebe la version:   node --version
El paquete "nodejs" de apt suele ser muy antiguo (Ubuntu 20.04 trae Node 10, 22.04 trae
Node 12). Para instalar una version actual:

   Opcion A (con sudo, NodeSource):
      sudo apt-get remove -y nodejs npm
      curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
      sudo apt-get install -y nodejs

   Opcion B (sin sudo, nvm):
      curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
      (abra una terminal nueva)   nvm install 20

Cortafuegos de Ubuntu (si otros equipos no conectan):
      sudo ufw allow 8443/tcp

Si el puerto esta ocupado, el servidor lo indica: use PORT=9000 node server.js

Controles: CH arriba/abajo cambia de canal. LLAMADA suena en todo el canal. ROGER es el
pitido de fin. SQUELCH es el ruido de apertura y cierre. FIJO: pulsar una vez para hablar
y otra para soltar. Tiempo maximo por transmision: 45 s.

Es un simulador educativo para redes de confianza: el audio no esta cifrado de extremo a
extremo ni hay cuentas de usuario.
